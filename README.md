#  Esercizi di Ripasso: Html · Css · Php · Java · MySql

[![GitHub repo](https://img.shields.io/badge/GitHub-Repository-blue?logo=github)](https://github.com/tuo-username/tuo-repo)

Questo repository raccoglie alcuni semplici esercizi di ripasso su diverse tecnologie web e di programmazione.  
Gli esempi sono pensati per consolidare le basi e comprendere meglio l’integrazione tra linguaggi frontend e backend.

---

##  Esercizio 1 – Form di Registrazione
- Creazione di un **form di registrazione** con i campi:
  - Nome  
  - Email  
  - Password  
- I dati vengono salvati in un **database MySQL** in modo sicuro:
  - Utilizzo di **hashing della password**  
  - Gestione tramite **state commitment**  
-  Per testare il funzionamento è necessario utilizzare **XAMPP** (o un ambiente equivalente).

---

##  Esercizio 2 – Somma di Numeri
- Pagina **HTML** con due campi numerici.  
- Tramite **JavaScript** e un pulsante, i valori inseriti vengono sommati.  
- Il risultato viene mostrato direttamente nella pagina.
